# Immune Summative II — Past-Paper Trainer

Installable offline trainer for **Human Immune System Summative II (BM33, L10–L19)**.

**Live app → https://bingoweetiwat.github.io/immune-sum2-trainer/**

264 items: 204 past-paper questions (189 MCQ + 15 written) from BM32, BM31, BM30,
BM29, BM28 and the AX legacy bank, plus 60 author-made drill questions kept in a
separate, clearly badged section.

Every answer is verified against the BM33 L10–L19 lecture decks and standard
immunology (Abbas / Janeway) rather than copied from student keys; where a key
looked wrong it is corrected openly (⚠).

## Install on iPhone / iPad
Open the link in **Safari** → **Share** → **Add to Home Screen**.
It then launches fullscreen with its own icon and works with no internet.

## Cross-device sync
Progress merges question-by-question through a **private GitHub Gist**.
Tap **☁ Sync setup** and paste a token with the `gist` scope — once per device.
The token is stored only in that browser's localStorage and is never committed here.
