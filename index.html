☁ Cross-device sync

Progress syncs through a private GitHub Gist. Paste a token once on each device. It is stored only in this browser and is never sent anywhere except api.github.com.

⚠ It must be a “classic” token with the gist box ticked. Fine-grained tokens do not work — GitHub's Gist API does not accept them, and no combination of repository permissions will help.

  1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
    Not “Fine-grained tokens”. The direct link is github.com/settings/tokens/new
  2. Click Generate new token → Generate new token (classic)
  3. Note: anything. Expiration: No expiration
  4. Tick the single checkbox labelled gist — “Create gists”.
    Do not use the “general use” preset; it leaves gist unticked. You do not need repo or anything else.
  5. Generate token, copy the ghp_… value, paste it below → Connect

Not connected — progress is saved on this device only.
